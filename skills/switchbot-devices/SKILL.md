For this kind of request, use tool_search to find this plugin's tools before web_search, then call them with tool_call. Write tool_search queries in English (for example: "SwitchBot devices").

Tools: `switchbot_devices`, `switchbot_command`, `switchbot_watch`. A command asks for approval.
